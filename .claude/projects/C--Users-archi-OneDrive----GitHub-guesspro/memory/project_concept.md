GuessPro는 "게임 플레이 영상을 보고 누가 플레이했는지 맞추기" 컨텐츠 사이트.

**Why:** 게이머/스트리머 시청자 대상으로, 영상만 보고 플레이어를 추측하는 재미를 웹에서 퀴즈 형태로 구현하려는 프로젝트.

**How to apply:** UI 및 기능 설계 시 항상 "영상 시청 → 플레이어 추측"이라는 핵심 루프를 중심에 둘 것. 범용 퀴즈 플랫폼이 아닌, 게임 플레이 영상 특화 컨텐츠임을 기억.
